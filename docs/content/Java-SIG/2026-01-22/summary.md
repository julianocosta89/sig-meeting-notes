## Key Topics
- Discussion on migrating to Invoke Dynamic (Indy) as the default setting for OpenTelemetry Java instrumentation.
- Concerns about the impact on existing extensions and user applications during the migration.
- Proposal to deprecate inline instrumentation and provide a migration path for users.
- Consideration of timing for changes in relation to the upcoming 3.0 release.
- Strategies for ensuring backward compatibility and minimizing disruption for users.

## Action Items
- Gather feedback on the proposed switch to Indy as the default setting.
- Develop a deprecation plan for inline instrumentation and communicate it to users.
- Create documentation outlining the migration path for extensions and instrumentation.
- Consider implementing a warning system for deprecated features in future releases.
