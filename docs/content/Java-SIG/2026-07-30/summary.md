## Key Topics
- Discussion on the integration of profiling-related features in OpenTelemetry Java, focusing on thread context and environment variables.
- Proposal to move attribute limits to the API level to ensure compliance with specifications and improve performance.
- Examination of the MicroProfile's dependency on OpenTelemetry API versions and the implications for LTS policies.
- Consideration of how to handle CVEs and support for older versions of the API.
- The need for a broader discussion on project policies regarding LTS versions and API guarantees.
