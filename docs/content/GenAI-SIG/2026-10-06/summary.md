## Key Topics
- Discussion on the distinction between "agent" and "workflow" in OpenTelemetry, focusing on a new operation concept called "turn."
- Proposal for a unified span type and metric name for agent and workflow invocations to simplify telemetry.
- Context propagation challenges, especially in distributed systems, and how to handle nested agent calls.
- The need for clear semantics around what constitutes a "turn" in the context of agentic systems.
- Exploration of naming conventions for spans and metrics related to agent and workflow invocations.
