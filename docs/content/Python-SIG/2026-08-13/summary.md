## Key Topics
- Discussion on the service name behavior in the SDK and its implications for users.
- Proposal for a new process to manage PR submissions, requiring issues to be opened before PRs.
- Need for opt-in support for new semantic convention attributes in messaging instrumentation.
- Concerns about GitHub workflow queuing times affecting PR merges.
