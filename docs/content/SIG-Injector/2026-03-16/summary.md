## Key Topics
- **KubeCon Preparations**: Discussion on vendor talks and preparations for KubeCon, including topics like sampling in OpenTelemetry.
- **Technical Committee Communication**: Ongoing discussions about project bootstrapping and improving communication regarding proposal timelines and expectations.
- **Injector Integration**: Efforts to integrate the OpenTelemetry injector into the Grafana operator, including a centralized instrumentation configuration approach.
- **CRD vs. Config Map Debate**: A debate on the use of Custom Resource Definitions (CRDs) versus configuration maps for operator configurations, focusing on the complexities and challenges of each approach.
- **Instrumentation Versioning**: The need for decoupling instrumentation image versions from the operator's versioning lifecycle to allow for more flexible instrumentation management.
