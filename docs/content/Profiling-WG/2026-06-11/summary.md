## Key Topics
- **Key Value Unit Proposal**: Discussion on the progress and next steps for the key value unit proposal, with Ivo Anjo agreeing to take over communication with the Technical Committee.
- **Profiling Roadmap**: Updates on the profiling roadmap and the need for a burndown for the next release.
- **Async Profiler Metadata API**: Jonathan Halliday raised concerns about compatibility with the async profiler's new span API and the need for collaboration to ensure interoperability.
- **Process Context for Go SDK**: Discussion on the implementation of process context for Go, emphasizing the distinction between thread context and process context.
- **GPU Profiling Interest**: Mattia Meleleo introduced the topic of GPU profiling and the potential collaboration with existing implementations.
