## Key Topics
- **Central OpenTelemetry Benchmark Proposal**: Discussion on the need for a project proposal process and the importance of approvals from maintainers across different language SIGs.
- **Support Maturity Model**: Review of the project proposal and the decision to remove it from the TC inbox until changes are made.
- **Post-Graduation Roadmap**: Clarification on the scope and purpose of the project, emphasizing the need for a clear roadmap for OpenTelemetry's future.
- **Spec Maintainership**: Proposal to create a dedicated maintainers group for the specification, allowing for more flexibility in TC member responsibilities.
- **Donation Proposal from Arise**: Discussion about the implications of accepting a donation for instrumentation libraries and the need for legal clarity regarding copyright and IP ownership.

## Action Items

- Remove the support maturity model from the TC inbox and communicate to the relevant parties.
- Draft a clearer proposal for the post-graduation roadmap and ensure all SIG leads commit to the project.
- Initiate the process for creating a dedicated maintainers group for the specification and clarify the roles of TC members.
