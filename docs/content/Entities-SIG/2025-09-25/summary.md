## Key Topics
- Discussion on the new OTEP for mutable resources and session entities in OpenTelemetry.
- Proposed changes to the metric recording process, emphasizing the need for session-specific meters.
- Introduction of entity parameters to enhance multi-tenancy capabilities and improve SDK initialization.
- Open questions regarding high cardinality entities, disjoint entity existence in instrumentation scope and resource, and guidance for developers on usage distinctions.

## Action Items

- Address open questions regarding safeguards for high cardinality entities and the implications for collector components.
- Clarify the distinction between resource and instrumentation scope entities for better developer guidance.
