## Key Topics
- **Nest.js 12 Support**: Discussion on merging a PR to add support for Nest.js 12, pending one approver's approval.

- **JSON File Exporter**: Proposal to add an experimental implementation for a JSON file exporter, with a preference for a single package handling multiple signals.
