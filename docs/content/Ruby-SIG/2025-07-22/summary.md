## Key Topics
- **Trace ID Based Ratio Changes**: Discussion on the stability and potential renaming of the trace ID based ratio due to refactoring, with plans to mark the current implementation as deprecated.
- **Exceptions and Span Events**: Ongoing discussions about potentially removing span events and recording exceptions using logs instead, with a request for review from languages without exception handling.
- **Auto Instrumentation Updates**: Notification about a new auto instrumentation release from another team that could cause confusion regarding upstream contributions.
- **OTLP Exporter Features**: Identification of missing features in the OTLP exporter, including support for HTTP/2 and JSON, with plans to create detailed issues for these.
- **Jaeger Remote Sampling**: Reopening discussions on Jaeger remote sampling due to its potential benefits and limitations in current sampling methods.
