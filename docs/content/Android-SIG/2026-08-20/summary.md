- Native crash handling strategies, focusing on capturing stack traces and the trade-offs between different approaches (e.g., using CrashPad vs. snapshotting).
- User attribution in telemetry, exploring the need for a convenience API to link user information with telemetry data.
- Session management updates and the potential formation of a working group to define session specifications across various platforms.
