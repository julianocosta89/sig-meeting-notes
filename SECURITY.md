# Security Policy

## Supported Versions

Only the latest version on `main` is actively maintained.

## Reporting a Vulnerability

Please report security vulnerabilities via a
[GitHub Security Advisory](https://github.com/julianocosta89/sig-meeting-notes/security/advisories/new)
rather than a public issue.

You will receive a response within 7 days. Public disclosure will be coordinated
after a fix is available.
